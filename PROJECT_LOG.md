Кандидаты Michroma/Aldrich/Orbitron отклонены — нет кириллических глифов (проверено рендером с `<meta charset="utf-8">`).
2. **DESIGN.md переписан полностью** — новая палитра (тёмный `#141414`/`#1b1b1b`/`#212121` + золото `#f6bd3a`/`#ffd673` + спектр направлений `--c-video`(фиолет)/`--c-design`(зелёный)/`--c-photo`(золото)/`--c-ai`(красный)), типографика, компоненты, motion-гайд (scroll-reveal/glow-hover/gradient-text/hero-drift/`prefers-reduced-motion`), правило «никаких эмодзи — только inline SVG», секция «Ассеты от заказчика».
3. **`css/style.css` переписан полностью** — новые CSS-переменные, шрифты, кнопки/карточки/бейджи под золото, `.service-card[data-dir]` с цвет-кодом направлений (бордер/иконка/glow по hover), hero с анимированными радиальными glow-пятнами (`@keyframes drift`), `.text-gradient` (золото→фиолет), `.reveal`/`.is-visible` для scroll-анимации с каскадом (`nth-child` delay) и полным откатом в `prefers-reduced-motion`.
4. **`header.html`/`footer.html`** — встроен `logo.svg` (золотая иконка + белый wordmark, читается на тёмном фоне сайта), пункт «Adervis PRO» выделен золотым (`.nav-cta`).

Контент (кейсы, шоурилы, 8 реальных отзывов) сохранён без изменений — это фактический материал клиента.

## Договорённости / решения

- Не клонировать сторонние Claude Code skill-репозитории в проект — ставятся отдельно как плагины (Anthropic Frontend Design, Interface Design — команды установки отправлены пользователю).
- Контакты: `+7 (922) 301-88-80`, `adervis.digital@gmail.com`. Соцсети: Behance (behance.net/adervisdigital), VK (vk.com/adervis_digital), Instagram (instagram.com/adervis_digital).
- **Adervis CRM** (бывш. «Adervis PRO») — отдельный продукт компании (CRM для продакшн-студий), живёт на `app.adervis.ru`, явно продвигается с главной и со страницы `/pro`. Фирменный градиент — `#6c00ff → #9b4dff` (переменные `--c-crm-1`/`--c-crm-2`/`--crm-gradient` в `style.css`).
- **Брендовая «грамматика» цвета**: золото = единственный CTA/бренд-акцент; цвет-код направлений (актуально с 2026-06-08) — **Видео = красный, Дизайн = фиолетовый, Фото = золото, ИИ = зелёный** — последовательно применяется во всех карточках услуг и иконках через `.service-card[data-dir="..."]`. - В шапке логотип всегда крупный (38px) с мягким золотым свечением; пункт меню «Adervis CRM» — золотая CTA-«таблетка», а не обычная текстовая ссылка; у остальных пунктов меню — анимированное золотое подчёркивание по hover.

- **Деплой = git push в `origin/main`** (репозиторий `adervisdigital-web/Adervis-website`, GitHub Pages/хостинг тянет с этой ветки) — отдельного CI/CD конфига в проекте нет.
