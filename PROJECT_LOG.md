## Контекст

Статический сайт (чистый HTML/CSS/JS, без фреймворков; с 2026-07-09 — devDependencies `terser`/`clean-css` только для `build/*.js`, в рантайме их нет). Компоненты `header.html`/`footer.html` — единственный источник правды, инлайнятся в каждую страницу скриптом `build/inline-components.js` (раньше подставлялись через `fetch()` в `js/app.js` уже после загрузки — из-за этого поисковики и пользователи без JS не видели навигацию и футер; см. `build/inline-components.js` для истории). Деплой: `npm run build` (inline-components → minify-assets → version-assets) → `git push origin/main`.

### ✅ Этап Brand 2.0.3 — Правки UX по скриншотам с живого сайта (готово, 2026-06-08)

Заказчик прислал скриншоты живого сайта с шестью точечными замечаниями:

1. **Логотип был «не виден»** — причина не в размере `<img>`, а в несоответствии `viewBox` реальной графике: `viewBox="0 0 3840 2160"` был куда больше самой отрисовки (фактический bbox артворка — `{x:110.99, y:636.99, w:3617.22, h:817.99}`, ~38% высоты viewBox), из-за чего лого рендерилось крошечным при ограничении по высоте. Исправлено точным кропом `viewBox="71 597 3697 898"` (замер `getBBox()` через headless Chromium) и пересчитан `width` у `<img>` под новое соотношение сторон (160×90 → 371×90) в шапке и футере — теперь логотип крупный и читаемый на всех брейкпоинтах.
2. **Плавающая шапка при скролле** — `.topbar` теперь прозрачная поверх hero и получает класс `.is-scrolled` (плавный переход на `--glass` фон + блюр + тень + бордер) после 24px прокрутки — `initFloatingHeader()` в `js/app.js`.
3. **Кнопка «наверх»** — круглая плавающая кнопка справа снизу (`.to-top`/`#toTop`, во `footer.html`), появляется после 480px прокрутки, плавный скролл к началу с уважением `prefers-reduced-motion` — `initBackToTop()`.
4. **«Adervis CRM» в шапке выглядел как главная кнопка** — конкурировал с золотыми CTA сайта. Переоформлен из золотой пилюли в спокойный «продуктовый бейдж»: ghost-обводка, золотая точка-индикатор, разделитель `.nav-sep` — теперь читается как ссылка на отдельный продукт, а не как основной призыв к действию.
5. **Заголовок hero переписан** — было нейтральное перечисление услуг («Видео, дизайн, фото и ИИ-контент — в одной команде»), стало продающее сообщение: «**Бренд, который заметят и запомнят:** видео, дизайн, фото, ИИ — в одной команде» (сохранены все 4 направления, фирменный градиент и УТП «одна команда», но теперь заголовок ведёт с обещания, а не со списка).
   - **Кнопка «смотреть видео»** — обдумана и сознательно НЕ добавлена: в `/video` нет встроенных плееров (только описательные карточки кейсов — у adervis.ru нет открытых стабильных публичных ссылок на ролики), кнопка на несуществующий плеер ввела бы в заблуждение. Возвращаемся к идее, когда появятся реальные embed-ссылки (см. TODO «прямые ссылки на видео» ниже).
6. **Логотипы клиентов «не видно»** — подтверждено программным анализом (canvas + luma-гистограмма по непрозрачным пикселям): ~17 из 32 используемых логотипов нарисованы светлым/белым (для тёмных поверхностей) и пропадали на едином светлом чипе `#f4f4f4` из Brand 2.0.2. При `rootPath === "/"` подмена не выполняется (нет смысла, и не превращается случайно в протокол-независимый `//путь`).

### ✅ Этап UI 1.1 — Скролл при загрузке, шрифт, мобильная 3D-иконка, плашка CTA, лого в светлой теме, 152-ФЗ (готово, 2026-07-19)
