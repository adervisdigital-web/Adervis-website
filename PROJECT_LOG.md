# ADERVIS Website — Журнал проекта

> Источник правды о статусе проекта между сессиями. Обновляется после каждого блока задач — перед чисткой диалога сюда выгружается актуальное состояние, и пушится на GitHub (`origin/main`, repo `adervisdigital-web/Adervis-website`).

## Контекст

Переносим adervis.ru на новый статический сайт (чистый HTML/CSS/JS, без фреймворков).
- Дизайн-система — `DESIGN.md` (Dark OLED Professional: DM Sans + Space Grotesk + JetBrains Mono, фиолетовый акцент `hsl(265,82%,58%)`, шкала отступов 4px).
- Компоненты `header.html` / `footer.html` подгружаются через `js/app.js` (`fetch` → `innerHTML`).
- Главная страница — обзорная/информационная (знакомство клиента с компанией). Страницы направлений (`/video`, `/design`, `/photo`, `/ai`) — продающие.
- Дополнительно продвигаем отдельный продукт — CRM **Adervis PRO** (app.adervis.ru) — должен быть на главной и на `/pro`.
