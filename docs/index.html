Политика конфиденциальности сайта adervis.ru и сервиса Adervis CRM, публичная оферта сервиса Adervis CRM.

Политика в отношении обработки персональных данных

1. Общие положения

1.1. Настоящая Политика конфиденциальности описывает порядок сбора, использования и хранения персональных данных: (а) посетителей сайта adervis.ru, заполняющих формы обратной связи, заявки на расчёт стоимости и калькуляторы услуг (далее — «Сайт»), и (б) пользователей сервиса «Adervis CRM» (далее — «Сервис»); совместно именуемых «Пользователи».

1.2. Использование Сайта или Сервиса означает безоговорочное согласие Пользователя с настоящей Политикой и указанными в ней условиями обработки данных.

2. Какие данные мы собираем

2.1. При заполнении форм на Сайте (заявка на консультацию, калькуляторы стоимости, форма записи на обучение) мы собираем:

  • Имя;
  • Контактные данные (телефон, адрес электронной почты или имя пользователя Telegram);
  • Краткое описание задачи, указанное Пользователем добровольно.

2.2. Для функционирования Сервиса мы собираем следующие данные:

  • Имя (или никнейм);
  • Адрес электронной почты (email).

2.3. Ни Сайт, ни Сервис не собирают и не хранят платёжные данные (номера банковских карт). Обработка платежей за доступ к Сервису осуществляется на стороне защищённого партнёра — сервиса «ЮKassa».

2.4. Сайт использует файлы cookie и сервис веб-аналитики «Яндекс.Метрика» (включая Вебвизор и Карту кликов) для сбора обезличенной статистики посещаемости — какие страницы просматривают, как перемещаются по сайту, из каких источников приходят. Эти данные не содержат имени или контактов Пользователя, если он сам не ввёл их в форму на просматриваемой странице. Пользователь может ограничить или отключить cookie в настройках своего браузера — часть функций Сайта при этом может работать некорректно.

3. Цели сбора данных

3.1. Данные, полученные через формы Сайта, используются исключительно для обработки заявки, расчёта стоимости услуг, подготовки и направления коммерческого предложения и обратной связи с Пользователем по указанным им контактным данным.

3.2. Данные cookie и веб-аналитики используются исключительно для анализа посещаемости и улучшения работы Сайта.

3.3. Данные Пользователей Сервиса используются исключительно для следующих целей:

  • Создание учётной записи и обеспечение авторизации в Сервисе;
  • Предоставление доступа к функционалу CRM-системы;
  • Идентификация платежей;
  • Обработка запросов в службу технической поддержки;
  • Отправка системных и транзакционных уведомлений.

4. Хранение и безопасность данных

4.1. Данные, отправленные через формы Сайта, передаются по защищённому протоколу (HTTPS) напрямую в закрытый чат мессенджера Telegram, доступный ограниченному кругу сотрудников Исполнителя, и используются для однократной связи по конкретной заявке.

4.2. Персональные данные пользователей Сервиса хранятся в защищённой облачной инфраструктуре платформы Supabase, обеспечивающей соответствие современным стандартам безопасности.

4.3. Исполнитель принимает все необходимые организационные и технические меры для защиты персональных данных Пользователя от неправомерного или случайного доступа, уничтожения, изменения, блокирования, копирования и распространения.

5. Передача данных третьим лицам

5.1. Исполнитель не передаёт персональные данные Пользователей третьим лицам, за исключением случаев:

  • Передачи данных заявки в мессенджер Telegram (компания Telegram FZ-LLC) — техническому средству связи, использующемуся для получения и обработки заявок с Сайта;
  • Передачи необходимой информации платёжной системе «ЮKassa» исключительно для целей проведения оплаты и формирования чеков;
  • Случаев, прямо предусмотренных действующим законодательством.

6. Изменение и удаление данных

6.1. Пользователь вправе в любой момент отозвать своё согласие на обработку персональных данных и потребовать полного удаления своих данных, переданных через формы Сайта, либо своего аккаунта в Сервисе и всей связанной информации.

6.2. Для удаления данных Пользователю необходимо направить соответствующий запрос в свободной форме на электронную почту: adervis.digital@gmail.com. Запрос будет обработан в срок, не превышающий 10 рабочих дней.
