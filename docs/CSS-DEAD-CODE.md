## Осталось: удалять только с визуальной проверкой ⚠️

Эти классы мёртвые по данным аудита, **но** сидят в секциях вперемешку с живыми
классами и в адаптивных блоках. Автоудаление без открытого браузера рискованно
(можно задеть живой селектор или оставить файл в полурабочем виде). По каждой группе —
открой соответствующую страницу, убедись, что блок реально отсутствует, и вырезай.
